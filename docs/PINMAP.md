# Распиновка T-Internet-COM

Распиновка, используемая на первом этапе проекта.

## microSD

| Сигнал | GPIO |
|---|---:|
| MISO | 2 |
| MOSI | 15 |
| SCLK | 14 |
| CS | 13 |

## Ethernet LAN8720

| Назначение | Значение |
|---|---:|
| PHY address | 0 |
| PHY power | GPIO 4 |
| PHY reset | GPIO 5 |
| MDC | GPIO 23 |
| MDIO | GPIO 18 |
| Clock | GPIO 0 OUT |
| PHY type | LAN8720 |

Линии RMII также занимают фиксированные GPIO ESP32 и не должны использоваться для других функций.

## RGB

| Назначение | GPIO |
|---|---:|
| WS2812 data | 12 |

## Будущий модем

| Назначение | GPIO |
|---|---:|
| ESP32 TX → modem RX | 33 |
| ESP32 RX ← modem TX | 35 |
| PWRKEY / reset control | 32 |

На первом этапе модемные GPIO только зарезервированы. Прошивка не формирует импульс PWRKEY и не открывает модемный UART.

## Предупреждения

- GPIO 0 участвует в загрузке ESP32 и в тактировании Ethernet PHY.
- GPIO 2, 12 и 15 относятся к strapping pins ESP32; внешние цепи не должны нарушать уровни во время загрузки.
- GPIO 35 является только входом, что подходит для линии RX ESP32.
- Перед подключением внешних устройств следует проверить ревизию конкретной платы и маркировку её контактов.
