# Дорожная карта

## Этап 1 — базовая диагностика

Статус: подготовлено, ожидает проверки на реальной плате.

- [x] структура репозитория;
- [x] единый файл конфигурации выводов;
- [x] USB Serial CLI;
- [x] RGB-индикатор;
- [x] запуск LAN8720;
- [x] получение адреса DHCP;
- [x] диагностика microSD;
- [ ] проверка сборки в Arduino IDE;
- [ ] испытание на конкретной ревизии платы;
- [ ] фотографии и журнал испытаний.

## Этап 2 — локальный журнал

- создание журнала событий на microSD;
- безопасное завершение записей;
- ротация файлов;
- отметки времени;
- фиксация потери и восстановления Ethernet.

## Этап 3 — Ethernet-узел

- локальная веб-страница состояния;
- проверка DNS и доступности заданного сервера;
- HTTP или MQTT телеметрия;
- настройка сети через конфигурационный файл.

## Этап 4 — сотовый модем

Начинается только после получения совместимого модульного модема.

- определение установленной модели;
- AT-терминал;
- SIM, IMEI, оператор и уровень сигнала;
- APN и мобильный Интернет;
- GNSS, если поддерживается модемом;
- SMS, если поддерживается тарифом и модемом.

## Этап 5 — резервирование

- Ethernet как основной канал;
- LTE как резервный канал;
- контролируемое переключение;
- буферизация данных на microSD;
- отправка накопленных данных после восстановления связи.

## Этап 6 — собственное изделие

- защищённое питание;
- изолированный RS-485;
- дискретные входы 12/24 В;
- аппаратный watchdog;
- RTC;
- корпус или DIN-рейка;
- защёлкивающийся держатель T-Internet-COM;
- испытания устойчивости и восстановления.
