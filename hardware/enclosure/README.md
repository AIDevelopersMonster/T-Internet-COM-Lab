# Держатель и корпус

Каталог предназначен для будущих файлов держателя платы:

- исходная CAD-модель;
- STL для пробной печати;
- чертёж с контрольными размерами;
- таблица ревизий;
- фотографии посадки платы.

Сейчас файлов модели нет, потому что геометрию необходимо снять с реального экземпляра платы. Основной принцип — съёмный поддон с боковыми защёлками и собственными монтажными отверстиями.
