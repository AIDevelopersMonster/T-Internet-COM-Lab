# T-Internet-COM Lab

Учебно-практический проект для платы **LILYGO T-Internet-COM на ESP32**.

Цель проекта — последовательно превратить плату из набора заводских примеров в понятный коммуникационный узел для реальных систем: Ethernet, microSD, локальная диагностика и, позднее, резервный LTE-канал через модемный модуль формата Mini PCIe.

> Текущий этап: **без сотового модема**. Модули находятся в стадии закупки, поэтому код модема пока не активируется и не требуется для сборки.

## Первый этап

Прошивка `ticom_board_check` проверяет доступные узлы платы:

- запуск ESP32 и вывод сведений о системе;
- командный интерфейс через USB Serial;
- RGB-светодиод WS2812 на GPIO 12;
- Ethernet PHY LAN8720;
- microSD по SPI;
- отображение IP-адреса, MAC, скорости и состояния линии;
- общий диагностический отчёт;
- безопасное резервирование GPIO модема без попытки его включения.

## Быстрый старт

1. Откройте `firmware/arduino/ticom_board_check/ticom_board_check.ino` в Arduino IDE.
2. Установите библиотеку **Adafruit NeoPixel**.
3. Выберите плату `ESP32 Wrover Module` или совместимую ESP32 WROVER.
4. Включите PSRAM, если соответствующая настройка доступна.
5. Загрузите прошивку и откройте Serial Monitor на скорости `115200`.
6. Введите `HELP`.

## Команды

```text
HELP          список команд
STATUS        полный отчёт состояния
INFO          сведения об ESP32
ETH           состояние Ethernet
SD            состояние microSD
SD LIST       список файлов в корне карты
LED RED       красный
LED GREEN     зелёный
LED BLUE      синий
LED WHITE     белый
LED OFF       выключить RGB
REBOOT        перезагрузить ESP32
```

## Важное ограничение платы

На основной плате нет удобных монтажных отверстий. Для реального изделия её нельзя оставлять свободно лежащей в корпусе или удерживать только кабелями. Проект предусматривает отдельную рамку или основание с боковыми защёлками, опорными площадками под платой и разгрузкой разъёмов.

## План развития

Следующие этапы после проверки базовой платы:

1. журнал событий на microSD;
2. локальная диагностическая веб-страница через Ethernet;
3. контроль доступности основного сервера;
4. подключение модема после его получения;
5. автоматическое переключение Ethernet → LTE;
6. буферизация данных при отсутствии обоих каналов;
7. собственная интерфейсная плата с RS-485 и защищённым питанием.

## Состояние

Проект находится на раннем аппаратном этапе. Прошивка подготовлена для первичного запуска, но должна быть проверена на конкретной ревизии платы.
